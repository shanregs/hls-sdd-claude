# Clarification Questions: 039 User Themes

**ANSWERED 2026-10-27: option A (defaults) for Q1, Q2 and Q3.**

Defaults are already applied in spec.md (Assumptions); answer only to change them.

## Q1. What happens to an unreadable custom accent?

| Option | Answer | Implication |
| --- | --- | --- |
| A (recommended) | Refuse as entered, offer an adjusted passing colour to accept | User stays in control; one extra tap |
| B | Silently adjust and save the nearest passing colour | Fewer steps; user may not notice the change |
| C | Refuse only, no suggestion | Simplest; frustrating for non-designers |

## Q2. Is the darker primary sidebar on the web a per-user option or always on?

| Option | Answer | Implication |
| --- | --- | --- |
| A (recommended) | Per-user opt-in, default off | Keeps Classic familiar; one extra stored flag |
| B | Always on for all presets | Simpler, bolder look; no choice |
| C | No darker sidebar | Smallest scope |

## Q3. How does a custom accent behave in light vs dark?

| Option | Answer | Implication |
| --- | --- | --- |
| A (recommended) | One accent stored, auto-adjusted per variant to pass | Always readable; the dark colour may differ slightly from the entered one |
| B | Separate accent for light and dark | Full control; double the entry and checks |
| C | Custom accent usable only in the variant where it passes | Simple; the accent disappears when the mode switches |

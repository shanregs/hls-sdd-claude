# Quickstart: User Themes

1. Start the backend and web as usual; run the migration (V140).
2. Sign in as any role; open Account, Theme. Pick Teal and Coral, Dark: the app restyles; reload, same result.
3. Sign in as the same user on the phone: Teal and Coral dark applies after sign-in.
4. Enter accent #FFEB3B: it is flagged unreadable with an adjusted suggestion; accept it; contrast ratios show.
5. Phone: airplane mode, relaunch: last theme shows. Change theme offline, restore network: the server holds it.
6. Toggle the darker sidebar (web); open a screen with status chips in each preset: chips stay green/amber/red.
7. Reset to default: Classic, Device mode on both clients.
8. Sign in as a different user: still Classic (themes are personal).
